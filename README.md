# AI_Apocalypse
Computes the likelihood that major AI companies have share prices that fall by 50% in two years.  I did this by hand a year ago, and vibe coded the site to automate.  

See https://prestonmcafee.github.io/AI_Apocalypse/ for both the computation output and explanation.  This site is available so that you can see the exact work behind it, but that is really Gemini's work product.
